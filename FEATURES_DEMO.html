ITO Single Page Layout

Transform Halaman Landing Page Menjadi Pengalaman PowerPoint Modern

Fitur Utama

Single Viewport

Tidak ada scrolling halaman. Semua konten dalam satu tampilan viewport yang fixed.

Vertical Dock

Navigasi floating dock vertikal di sisi kiri dengan animasi smooth dan tooltip.

Modal Cards

Konten ditampilkan dalam modal card yang elegan dengan scroll parallax.

PPT Animations

Transisi dan animasi seperti PowerPoint untuk pengalaman yang menarik.

Mobile Ready

Dock berubah menjadi bottom bar di mobile dengan touch gestures.

Keyboard Nav

Shortcut keyboard untuk navigasi cepat antar section.

Mobile Experience

Di perangkat mobile, floating dock otomatis berubah menjadi bottom navigation bar dengan fitur:

  • • Floating button untuk toggle menu
  • • Touch-friendly icon sizes
  • • Swipe down gesture untuk close modal
  • • Full-screen modal cards
  • • Optimized animations untuk performa
